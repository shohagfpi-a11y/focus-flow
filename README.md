# Focus Flow

A simple, single-file Pomodoro timer and task tracker that runs entirely in the browser.

## Features

- Focus / Short Break / Long Break timer modes (25 / 5 / 15 minutes)
- Task list — add tasks, select one to focus on, mark done, delete
- Daily streak, today's count, and total completed sessions
- Progress saved locally via `localStorage` — no backend required

## Usage

Open `index.html` in any modern browser. No build step or dependencies needed.
